# PROJECT BRIEF — Your Choice Trading Terminal

## Project Identity
- **Website Name:** Your Choice Trading Terminal
- **Logo:** Full name written in gold — "Your Choice Trading Terminal"
- **Purpose:** Personal trading dashboard / terminal
- **Domain:** To be decided later

## Design & Vibe
- **Theme:** Premium & Bold
- **Background:** Deep black (#0a0a0f, #0f0f14)
- **Accent:** Gold only (#d4af37, #f0c040, #fbbf24)
- **Up Color:** Gold (#f0c040)
- **Down Color:** Muted red (#ef4444)
- **Fonts:** Space Grotesk (headings/body) + JetBrains Mono (prices/data)
- **Feel:** Luxury private-wealth trading terminal

## Pages
1. Home — Hero, live ticker, market overview cards
2. Forex — EUR/USD, GBP/USD, USD/JPY, USD/CHF, AUD/USD, USD/CAD, NZD/USD
3. Commodities — Gold, Silver, Platinum, WTI Oil, Brent Oil
4. Crypto — BTC, ETH, SOL, BNB, XRP
5. Indices — SPX, NDX, DAX, FTSE 100, Nikkei 225
6. Interest Rates — Fed, ECB, BOE, RBI, BOJ central bank rates
7. News — Live TradingView news + category filters
8. Market Analysis — Sentiment, Fear & Greed, COT data overview
9. Calculator — Pip Calculator + P&L Calculator + Currency Converter
10. Contact

## Charts
- Type: Candlestick (OHLC)
- Timeframes: 1m, 5m, 15m, 1H, 4H, 1D, 1W
- Source: TradingView embedded widgets (100% real live data)
- Ticker Tape: Live scrolling on every page

## Tech Stack
- Plain HTML + CSS + Vanilla JS
- No frameworks, no build tools
- Runs by opening index.html in browser
- Deployable on GitHub Pages / Netlify
